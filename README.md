# ADM — Anything Download Manager

A fast download manager for **Windows, macOS and Linux**: multi-connection downloads with resume, BitTorrent, video and stream downloads (HLS/DASH), a scheduler with queues, a site grabber, and a browser extension for Chrome, Edge, Brave and Firefox.

**Website:** https://simpletoolsindia.github.io/adm/

## Download

Get the latest version from the [Releases](https://github.com/simpletoolsindia/adm/releases/latest) page or the [website](https://simpletoolsindia.github.io/adm/#download). The browser extension is included in every download; see the website for how to install it.

## Privacy

ADM has no accounts, analytics or tracking, and the browser extension only talks to ADM on your own computer. Details: [Privacy Policy](https://simpletoolsindia.github.io/adm/privacy.html).
